One brutally honest but still polite out-of-office auto-reply — written by `main.py` (Python standard library only) to `/output/entry.txt`. Deterministic: the same line on every run.

## Entry

> I'm out of office until Monday, and I'll be honest: I'm not checking email because every time I do, my holiday quietly becomes work — thank you for waiting.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
